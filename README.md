## System analysis & Design

The project designs a digital Restaurant Order Management System aimed at replacing traditional paper-based systems.
The document covers problem analysis, functional and non-functional requirements definition, and the Agile development methodology.
It also includes engineering diagrams and design models such as Use Case, DFD, Class Diagram, and behavioral diagrams.
Finally, it presents the proposed user interfaces for various system roles such as the waiter, chef, cashier, and manager to facilitate operations.
